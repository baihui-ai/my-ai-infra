# 内置图示源码与动画设计

## 需求与范围

用户要求保留自动 SDD 开发，将 Java、SQL、表结构和前端小窗口经验融入阶段规范；完整复制自研 Skill 源码并统一维护，绘图标识统一为 my-tech-diagram，支持适用图示的动画，最终提供评测。用户随后明确取消飞书文档，并要求采用本项目自己的模板；当前按本地文档交付，不再内置lily-doc。

| AC | 可观察条件 |
|---|---|
| AC-01 | my-tech-diagram 的入口、参考、样图、showcase 与评测随包安装，无维护者主目录依赖，源码与调用标识统一 |
| AC-02 | java-dev完整源码与本项目标准/简版模板随包管理，当前用户规则优先于历史示例，六字段使用 create_by/update_by |
| AC-03 | PRD/设计调用内置画图能力，方案评审核对图文证据，HTML 复用静态与动画资产 |
| AC-04 | 静态 SVG 完整保留，可控 HTML 支持步骤焦点、播放/暂停/重置/前后步骤，减少动画、离屏暂停、小窗口和静态回退 |
| AC-05 | 样图二进制安装后字节一致，重复同步稳定，merge 保留定制并保存候选，replace 可恢复包内容 |
| AC-06 | 自动测试、浏览器评测、安装包验收和评测用例/报告可复现；当前本地模板、工作台与图示运行分别有证据 |

## 关键选择

- 源码直接复制入 assets/skills，包含图片与参考；注册为普通 Skill，复用现有装配及工具链接。保留源码管理的统一入口，代价是包体增加约 6 MiB，故补齐二进制资源装配，个人文本编辑/导入仍保持原有契约。
- 二进制以 kind=binary、SHA-256 和 base64 内容进入预览/事务，磁盘保持真实字节；安装前状态复核、备份、回滚沿用现有事务。merge 保留本地并写入原始字节候选；不将图片当 UTF-8 文本。
- 先按 Skill 手写静态 SVG，再用原生 Node 脚本包装交互 HTML，无运行时第三方依赖。静态图用图片隔离展示；焦点步骤不改变领域关系，事件便签不加入时序。替代方案包括外部绘图插件/浏览器在线渲染，因源码统一管理和离线运行要求未选。
- HTML 动画使用有终点的定时步骤，不自动循环；仅焦点透明度过渡，系统减少动画时关闭自动播放，允许逐步阅读。可逆：使用静态 SVG 不依赖动画 JS。
- 文档统一采用本项目自己的标准/简版模板；技术规则在自身阶段规范维护，取消云端同步、授权和外部模板Skill。保留用户的既有模板定制与无关配置。

## 验证与剩余项

自动覆盖脚本输入、输出保护、二进制安装/重复同步/冲突、浏览器操作、源检查与分发。宿主模型在未知领域需求下能否正确识别实体/事件等需要独立语义评测，不能由装配或按钮测试代替；Windows实机按用户要求保留未验证项，取消的云端能力不再作为验收条件。
