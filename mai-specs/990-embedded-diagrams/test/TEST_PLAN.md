# 图示与工作流评测计划

[需求与设计](../design/TECH_DESIGN.md)，[实际评测记录](../EVALUATION.md)。

## 自动与分发

运行 npm run release:check，核对源码检查、全量隔离测试、实际 tarball 资源字节及动画脚本执行。运行 npm run test:diagrams 验证动画完整静态展示、前后步、播放/暂停/重置、末步停止、减少动画、离屏暂停和 480px 小窗口。运行 npm run test:web 检查工作台原有行为及 1440/1280/390/375 布局。

## 宿主语义

唯一用例源：assets/skills/my-tech-diagram/evals/evals.json，共 14 条。逐例在隔离输出目录执行，分别保留 with_skill 和 without_skill 原始产物与真实检查；缺资料的用例预期为缺口回复，不能补造业务内容以完成出图。

my-tech-diagram 使用隔离项目安装的源码、参考图和脚本，证明无需全局插件。领域模型检查单张完整图、类型/关系/多重性和聚合边界；事件图检查业务事实、命令查询及外部触发语义，无虚构因果箭头；架构/拓扑检查已确认组件、区域与协议。动画复用批准图，简单查询不强制画图。

新增 npm run eval:diagrams 对已产生的输出执行元素、XML/viewBox、数量、箭头、卡片文字边界、离线 HTML 和小窗口检查。机械结果不能代替全部业务语义断言，最终逐例人工核对模型、图片和验证证据。没有实际执行的条件标待验证，不把测试计划作为通过证据。

## 结果门槛

本次实现对应的断言必须有当前证据；失败先归因并修复再用同条件复验。统计比较逐组给出样本数和实际覆盖，不将缺少的 token/耗时记为零。macOS 证据不代表 Windows 实机已验收，用户要求保留Windows未实机项；本次新增核对项目模板安装/定制保留、旧Skill选择退出、旧云端API/回调404和私有配置不被读取/改写，取消能力不再进行验收。
