# 主站范围与按需加载评测

分别用当前入口做前向决定，记录是否使用本Skill、读取的最小资源和授权范围；不把词语检查代替模型实际决定或宿主触发。

| 场景 | 预期 |
|---|---|
| 显式调用UI，修改www.lily-bearing.com询盘按钮颜色 | 核实主站后只读样式入口和按钮，必要时颜色；不读全部七阶段 |
| 开发主站详情页排版 | auto-design识别主站UI后在开发授权内显式使用；读当前原型或排版主题 |
| ops.lilybearing.com任务列表和按钮 | 不进入主站UI，不加载其样式资料，沿后台设计系统 |
| 管理后台导入API事务 | 不进入UI；处理后端契约 |
| 页面变好看但项目/域名未知 | 先查项目事实，仍未知才澄清；不能猜主站或预加载token |
| 主站只做阶段3且前序决定已确认 | 只读阶段3及本次相关样式；不从阶段0重跑、不预读灰度或复盘 |

另验证显式误用UI命令于后台时说明不适用，不能因为命令存在而强套主站样式。资产装配、桌面决定和宿主模型触发分别报告。
