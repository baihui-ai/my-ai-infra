# LILY 主站 UI

仅在用户明确调用本Skill，或已授权开发流程明确调用本能力时使用。适用于lily-bearing.com主站，默认英文站；主站规则不自动覆盖公司运营后台、CLI工作台或其他网站。保留用户已确认的范围与项目规范。

调用前先核对域名、路由、仓库说明或用户明确范围是否属于LILY主站；仅出现“页面/按钮/表格/前端”不能证明是主站。ops.lilybearing.com、运营后台、管理系统及纯后端/API任务不加载本Skill的样式资料，即使误点本命令也说明不适用并回到该项目原有规范。范围未知时先查当前项目事实，仍无法判断才询问，不猜测套用主站规范。

## 先确定本次模式

从当前请求、已有方案与产物判断任务，不重复询问已确定的信息。只加载下表中当前阶段的一项资源及其确实需要的依赖，不预读全目录、完整流程或所有规范。不因未来阶段资料缺失阻塞当前可完成工作。

| 当前任务 | 先读 | 需要时再读 |
|---|---|---|
| 仅样式/颜色/按钮/排版/局部组件 | [样式入口](references/style-guide.md) | design-tokens中的相关小节 |
| 立项与范围（阶段0） | [立项](references/stage-0.md) | 当前线上实验及已有决策 |
| 数据诊断（阶段1） | [诊断](references/stage-1.md) | 获授权的同口径数据 |

## 共同边界

样式小改只执行当前范围，不强制跑七阶段、拉业务数据、选5家对标、产出多方案或等待4个闸口。完整页面改版才按阶段推进；当前只读当前阶段，已确认闸口直接复用记录，真实待决业务事项才交负责人选择。缺少数据就标记未核实，不能编造流量、转化或客户依据。

品牌色、CTA语义和商标规范以样式参考为准；产品正文不嵌解释标签，设计说明另存。响应式按当前范围实测，未运行浏览器不报兼容通过。安装/调用不授权发布、部署、AB配置或生产变更。

不默认读取员工历史对话、不自动抽取个人记忆、不注册复盘。确需复盘时只处理用户本次明确提供/授权的范围，输出脱敏规则候选，团队确认后维护源码。

每次只汇报当前阶段的依据、产物、实际验证和缺口；后续阶段已获连续授权则接续，否则在请求范围内停止。[完整流程档案](references/full-workflow.md)仅在用户需要总览或跨阶段对照时读取，当前入口边界优先于档案中的默认触发及历史表述。
