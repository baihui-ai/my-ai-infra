### 阶段 0：立项定界与冲突排查
1. 明确本轮「改什么」与「明确不改什么」（语言站、终端主口径、哪些既有页面/网址保留不删）。
2. **线上在测实验隔离核查**：查当前全站正在运行的 AB 实验（如 `prod-navigation-page`、`prod-detail-quote`、`prod-mobile-pdp-v1` 等）及其触发条件与脚本，写明本轮绝不能触碰的 DOM 与 JS 文件边界。
3. 查历史决策日志（`docs/decisions-log.md`）、相关会议纪要与飞书待办，防止推翻已定口径。
4. **交付**：《改版范围与隔离边界清单》。
5. **🔴 闸口 G1（人工确认）**：确认语言站范围、主次终端口径、线上实验隔离方式及本次改版第一业务目标。
