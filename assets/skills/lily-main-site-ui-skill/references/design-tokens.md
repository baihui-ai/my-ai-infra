## 二、按钮颜色语义铁律（防止视觉噪音）

1. **实心黄 `#f7c542`（配 `#132538` 字）**：**全站 100% 独占只给最重要的发询盘按钮**（页头/页脚 `Request a Quote`、详情页 `Bulk / Custom Quote` / `Request Quote & Lead Time`、联系页 `Send message`、报价页 `Request quote`）。视频播放钮、搜索钮、筛选钮、下载钮**一律禁用实心黄**。
2. **品牌饱和度与调性边界锁（2026-11-24 定）**：LILY 整站为中低饱和、沉稳克制的工业钢蓝＋冷钛灰调性。**严禁**为追求对比度而跨出色域硬塞高饱和消费科技蓝（如 `#1f76ec`）或霓虹色；首屏搜索主按钮锁定为与顶栏 `#36648a` 同血统的**品牌钢蓝提明胶囊版（`linear-gradient(180deg, #2e6fa3 0%, #21547d 100%)`，白字对比度 7.5:1，配合 `border-radius: 999px` 磨砂玻璃检索台）**。
3. **钢蓝描边白底 `#36648a`**：用于与询价并列的主动作（如移动端有价详情页左按钮 `Add to Cart`）。
4. **深蓝 `#24506f` / 深藏青 `#0f2a44` 白字**：用于在线结账（`Proceed to Checkout`）及其他非询盘核心动作（`Submit application`、`Request supplier documents`）。
5. **品牌蓝 `#1f5f99`**：用于文字链接（统一 15px / 800 / 带箭头）及白底上的 `Copy Email` 按钮；蓝底上的 Copy 按钮改用 `#24506f`。

## 三、字体与字号阶梯（全站 Manrope）

全站统一使用 **Manrope**（禁用额外的装饰衬线字体如 Playfair Display）。整页字号种类控制在 **≤ 15 种**以内：

| 层级 | PC 宽屏（1920） / 窄屏（≤1500） | 字重 | 行高 |
|---|---|---|---|
| 页面大标题 H1 | `52px / 42px` | 700 | 1.15 |
| 板块大标题 H2 | `40px / 36px` | 700 | 1.16 |
| 子块标题 | `32px / 28px` | 700 | 1.20 |
| 数据带大数字 | `38px` | 800 | 1.05 |
| 卡片核心数字 | `26px` | 800 | 1.00 |
| 引语 | `22px / 20px` | 400 | 1.60 |
| 卡片标题 | `20px / 18px` | 700 | 1.35 |
| 首屏导语 | `19px / 18px` | 400 | 1.65 |
| 正文 | `17px / 16px` | 400 | 1.65 |
| 按钮 / 文字链接 | `15–16px` | 800 | — |
| 卡片正文 | `15px` | 400 | 1.60 |
| 板块眉题（大写，字距 `0.16em`） | `14px`（`#36648a`） | 800 | — |
| 标签 / 次要说明 | `14px / 12px`（卡片标签大写，字距 `0.08em`） | 400 / 800 | — |

**移动端硬下限**：按钮高度 `≥ 46px`、按钮字号 `≥ 14px`、正文最小 `≥ 12.5px`、所有表单 `<input>/<textarea>/<select>` 字号 **`≥ 16px`**（防止 iOS Safari 聚焦自动缩放）。

## 四、版式间距、图片比例与纯 To B 禁用清单

- **PC 内容宽与留白**：主内容宽 `1200px`（`≤1699px` 左右留白 `24px`）；板块上下留白 `112px`（`≤1500px` 为 `92px`）；眉题→H2 `16px`、H2→导语 `20px`、导语→卡片 `48px`。
- **卡片与提示条统一样式**：只留两类——内容卡（无框或 `#f2f4f6` 浅灰卡）、提示条（统一 `1px #dfe4e9` 细框 ＋ `4px #f5bf2f` 黄左线）；圆角仅按钮与框用 `4px`，徽章用胶囊形，其余 `0`。
- **图片与媒体规范**：全部按显示宽度 **2 倍导出 WebP**（`loading="lazy"`，首屏主图除外）；工程图画面**严禁压黑底文字条**遮挡右下角 LILY 标题栏（移动端在右上角空白处放 `30×30px` 单色放大镜加号图标）。
- **环境背景视频规范（2026-11-24 定）**：① 使用原生 1080p 真实产线素材（剔除会议室/更衣室），生产环境必压至 **≤5–6 MB**（VP9 WebM + H.264 MP4 `faststart` 双源）并 `<link rel="preload" as="image">` 预加载首帧封面；② 采用**单层轻遮罩**（中段不透明度 ≤35%，仅底缘平滑过渡至深色底座）配合局部 `text-shadow` 保证字清画透，**严禁**叠两层重暗蒙版致画面发糊；③ 氛围动态背景**不放冗余的 `Pause` 或 `Watch Factory Film` 按钮**（仅 JS 静默遵守 `prefers-reduced-motion: reduce`）。
- **质量认证印章与商标合规规范（2026-11-24 定）**：① 严禁在官网直接贴用 ISO 官方标、SAE／IAQG 官方标或 **IATF 官方绿地球商标**（IATF 仅允许印在官方证书文件上）；② 采用经发证机构书面授权的组合标，或使用独立矢量 SVG 定制双环精工金属印章（须做到上下环绕刻字**均正向从左至右可读**、按行业属性区分质感且克制庄重），并在副标亮出真实发证机构（`HBC`、`URS (UKAS)`、`AENOR`）配 PDF 直链。
- **纯 To B 禁用清单**：
  - 禁用 `🚚` 小卡车等 To C 零售图标；
  - 禁用 `Free US shipping` 包邮促销腔与多余的 `Factory Direct` 推销标签；
  - 禁用紫色 `Buy with shop` 快捷支付按钮（实测近 180 天美国 622 笔真单 Shop Pay 为 0）；
  - 禁用任何与事实不符的“限时折扣/倒计时/虚构库存紧张”电商套路。
- **全站统一页头与页脚**：单页改版一律复用第 36 版正式页头与第 3 版正式页脚，严禁为单页自造专属页头/页脚；页脚电话只做纯文本、不做拨号链接；Copy 邮箱按钮复制写死地址（绕开 Cloudflare 邮箱混淆）。
