### 阶段 4：整页视觉审查与多视口自动化验收
1. 严格按 [visual-qa.md](visual-qa.md) 用真实无头浏览器跑自动化盘点：
   - **PC 桌面端必测 5 档（含 2K 大屏防假底）**：`2560×1320`（27 寸 2K/4K 大屏浏览器）、`1920×1080`、`1920×920`（扣除浏览器栏与 Windows 任务栏的真实可视高度）、`1440×900`、`1366×768`，截图必标视口并用 `window.innerWidth` 回读确认。
   - **移动端必测 2 档**：`390×660`、`360×800`，横向溢出严格 `= 0 px`，表单输入框字号 `≥ 16px`。
   - **防假底与交互状态必验**：严禁首屏固定封顶（如 `980px`）与下屏大上留白叠加出纯白死缝（假底效应 False Floor）——须采用「全分辨率露头窥视（`calc(100vh - 140~150px)`＋下屏顶对齐与紧凑上距 `≤36px`）」使下屏真实标题在全部 5 档桌面首屏自然露头，或采用真无封顶 `100vh` 贴底＋下探导引；同步验真透明悬浮顶栏首帧零蓝闪、中段滚动防重叠、搜索联想浮层不被裁切、全页滚扫触发 `loading="lazy"` 后核验破图数。
2. 必过硬门槛：正文与次要文字对比度全部满足 WCAG ≥ 4.5:1；字号种类收敛、同级眉题/卡片/提示条样式统一；图片按显示宽度 2 倍导出 WebP、背景视频转码 ≤6 MB 并预加载封面；核心内容与结构化数据 100% 直出在初始 HTML 内；禁词、商标合规与品牌口径零违规。
3. **交付**：《整页视觉与兼容性体检报告》及修完后的终稿原型。
