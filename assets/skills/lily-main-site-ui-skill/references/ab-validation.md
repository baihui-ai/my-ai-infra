## 三、双轨 AB 验证与放量模型（阶段 6）

### 轨道 A：大样本页面（首页、全站导航、桌面详情页等）—「三层分工制」
判胜铁律：**主裁判显著胜出 ＋ 护栏未掉坑 ＋ 总账净增**（三层不直接相加）：

| 层级 | 监控对象 | 作用 |
|---|---|---|
| **第一层·主裁判区** | 本页改版核心目标组件产生的提交/进入量、**4 分+ 高质量询盘**（不含 4.1）及线索质量结构（3.0+ / 0 分占比） | 保持归因纯度，不被旁路噪声稀释 |
| **第二层·旁路与护栏区** | **4.1 Shopify 实付订单**笔数与金额、在线 Chat 留邮箱量及 4 分+、跳去报价/联系页填表量；对离线复制邮箱固定标口径盲区 | 防“左手倒右手”挤占或逼走在线买家 |
| **第三层·公司总账区** | 全站 4 分+ 高质量总询盘（不含 4.1，表单＋Chat 去重）与全站总询盘 | 确认公司全局净增量 |

### 轨道 B：小样本页面（如月均填表 < 50 单的移动端详情页）—「14 天 50/50 护栏灰度」
不苦等数月常规双侧显著性，满 **14 天** 核验以下 4 项即决策：
1. **信任护栏**：干净样本分流均衡检验（SRM）`p > 0.01`；Sentry 新增报错 = 0；表单 HubSpot 打分非空率 = 100%。
2. **主判指标（上游复合意向）**：复合意向触发率（开始填表 ∪ 加购 ∪ 复制型号 ∪ 下图纸 去重）实验组相对对照组持平或正向。
3. **商业底线护栏（非劣效）**：实验组「表单提交＋实付真单合计率」单侧 90% 置信下限不低于对照组 80%，无连续 5 天归零或腰斩。
4. **体验护栏**：客户端实测 `LCP P75 ≤ 2.5s`、`INP P75 ≤ 200ms`、`CLS P75 ≤ 0.1`；抽查 20 段 Clarity 美国录屏确认无死点击与遮挡。
- **放量后追踪**：达标即 100% 全量释放，第 28 天与第 60 天复核谷歌 CrUX 现场性能与 GSC 同页双端排名/点击率差值；任意护栏触发红线立即 Bucketeer 一键切回 0%。
