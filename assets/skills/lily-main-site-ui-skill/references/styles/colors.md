## 一、锁定色板与 WCAG 对比度基线

| 用途 | 色值 | 悬停 / 配字 | 白底 / 灰底对比度说明 |
|---|---|---|---|
| **页头 / 页脚 / 吸顶条 / 眉题 / 次级主描边** | `#36648a`（钢蓝） | 白字或深色描边 | 白底 6.27:1 / 灰底 5.69:1 |
| **核心询盘主按钮（唯一用途）** | `#f7c542`（强调黄） | 字 `#132538`；悬停 `#f0b527` | **仅限核心询盘提交入口** |
| **强调装饰黄线** | `#f5bf2f` | 仅用于 2–4px 线条、引号 | **严禁用于文字** |
| **在线结账 / 页脚 Copy 按钮** | `#24506f`（深蓝） | 白字；悬停 `#1b3f59` | 用于结账主按钮、蓝底 Copy 按钮 |
| **其他非询盘主按钮 / 认证徽章** | `#0f2a44`（深藏青） | 白字 | 对比度 14.6:1（如申请经销商、索取资料、发简历） |

| **正文文本** | `#3d4a57` | — | 9.07:1 / 8.23:1 |
| **次要说明（取代发虚的 `#6b7684`）** | `#5f6a77` | — | 5.51:1 / 4.99:1（全部 ≥ 4.5:1） |
| **文字链接 / 浅底 Copy 按钮** | `#1f5f99` | 悬停 `#174a78` | 6.66:1 / 6.04:1 |
| **价格 / 现货库存绿** | `#237e4b` | — | 仅用于明确现货/价格强调 |
| **底色交替与分隔线** | `#ffffff` / `#f2f4f6`；分隔线 `#dfe4e9` | — | 相邻大板块白灰交替 |
