# 主站样式按需入口

仅在确认LILY主站UI任务后使用。先选当前改动的一个主题，只读对应资料；跨主题的改动再读确实依赖的主题，不预读全部色板、完整流程或未来阶段。

| 本次问题 | 读取 |
|---|---|
| 品牌色/颜色/文字对比度 | [颜色](styles/colors.md) |
| 按钮颜色、询盘CTA、搜索/播放等按钮 | [按钮](styles/buttons.md)，需要时读颜色 |
| 字体、字号、层级 | [排版](styles/typography.md) |
| 页面间距、图片/视频、品牌文案和认证 | [布局与素材](styles/layout-media.md) |

固定基线：核心询盘Request a Quote独占黄色#f7c542，其他控件使用中低饱和工业色域；英文To B制造企业表达，主标题采用正面表述；商标和认证依据真实授权，不伪造。正文不混入设计解说，说明另存。组件复用现有项目实现，覆盖非全屏与窄窗口，不为引入规范改造无关页面。

完整[Design Tokens档案](design-tokens.md)只在查跨主题上下文或用户明确需要全量对照时读取。局部样式任务不强制业务诊断、5家对标、AB或七阶段审批。
