# 可控图示动画

静态 SVG 和关系模型是完整文档资产；动画用于解释同一事实，不增加关系或暗示原图没有的时序。静态图默认完整可读；演示保留播放、暂停、上一步、下一步和重置。

先完成 SVG 的语义与视觉检查。对架构图按业务链路讲解，对时序/状态/机制图按真实路径安排步骤。领域事件图仅逐组强调，不添加流动箭头、时间轴或命令事件的虚假先后。

使用内置 `scripts/animate-svg.mjs`，输入静态 SVG 和步骤 JSON，生成同目录 HTML，无需安装绘图命令或运行时依赖。步骤结构：`{"steps":[{"label":"读取请求","detail":"验证已存在的输入约束","box":{"x":40,"y":80,"width":200,"height":100}}]}`。box 为 SVG viewBox 中的坐标，可省略；坐标必须在画布范围内，步骤说明以已有模型为依据。

```bash
node .agents/skills/my-tech-diagram/scripts/animate-svg.mjs --svg path/to/diagram.svg --steps path/to/steps.json --out path/to/diagram.html
```

- 不覆盖手写 HTML 或未知输出，不沿输出路径的软链接写入；受管生成页可重建。
- 使用静态 SVG 图片呈现完整图，步骤只增加焦点框和文字说明；不改变已有图形和连线。输入拒绝脚本、事件属性、foreignObject、外部资源和实体声明。
- 不自动循环播放；离屏、切换标签或用户暂停时停止。系统减少动画时禁用自动播放，仍可手动逐步查看。仅焦点框使用短 opacity 过渡，不持续驱动布局。
- 小窗口保留完整图的横向滚动与说明，键盘可操作所有按钮；打印时隐藏控件和焦点，保留静态全图。
- 不支持动画的阅读环境使用静态图，动画 HTML 作为本地审阅产物；静态图和交互页分别验证。

检查截图、步骤和播放状态；仅生成 HTML 不算浏览器验收。评测覆盖静态可读、步骤顺序、暂停/重置、末步停止、减少动画、小窗口、恶意 SVG 与输出冲突。

SVG 必须独立按 XML 解析，再检查实际图片解码；不能只内联进 HTML 后检查 DOM，因为浏览器会自动修复重复属性等错误。包装脚本会拒绝重复 XML 属性，但该预检不能替代完整 XML 与渲染检查。

分组焦点必须从源 SVG 的真实分组边界和最外侧卡片计算，并逐步截图核对：包含该组标题、全部卡片及必要角色，但不能覆盖相邻领域标题或卡片。旋转便签需按变换后的几何范围检查，不能仅检查焦点框位于整张画布内。旧批准图缺少稳定节点 ID 时保留原图，用模型映射核对，不为动画改写批准图。
