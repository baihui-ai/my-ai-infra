# 关系模型：deploy-network-topology（部署网络拓扑图）

- 图类型：网络拓扑图（Network Topology）
- 风格：科技炫酷风（tech）
- 布局：自上而下 用户 → CDN → ALB → 应用层（可用区 A/B）→ 数据层（私有子网）

## 假设（门禁降级标注，非用户提供，均为业界标准默认值）

- 用户→CDN、CDN→ALB：HTTPS:443（CDN→ALB 为回源）
- ALB→应用服务器：HTTP:8080
- 应用→MySQL：TCP:3306；应用→Redis：TCP:6379
- MySQL 主→从：binlog 异步复制，TCP:3306，虚线表示
- IP 段/hostname 按「按需脱敏」省略，不编造

## 分组（安全域边界）

| 分组框 | 包含节点 | 画法 |
|---|---|---|
| VPC · 虚拟私有云 | CDN、ALB、应用服务器 A/B、MySQL 主/从、Redis 集群 | 虚线圆角矩形（除用户外全部在内） |
| 可用区 A | 应用服务器 A | VPC 内虚线子框 |
| 可用区 B | 应用服务器 B | VPC 内虚线子框 |
| 私有子网 · 数据层 | MySQL 主、MySQL 从、Redis 集群 | VPC 内虚线子框（紫色强调） |

互联网用户在 VPC 边界之外。

## 节点

| 节点 | 类型标注 | 位置 | 强调 |
|---|---|---|---|
| 互联网用户 | 外部用户 · Internet | 顶层居中，VPC 外 | 普通 |
| CDN 加速 | 内容分发 · CDN 节点 | VPC 内第一层 | 青色描边 + glow |
| ALB 负载均衡 | 负载均衡 · LB | VPC 内第二层 | 青色描边 + glow |
| 应用服务器 A | App Server | 可用区 A | 普通 |
| 应用服务器 B | App Server | 可用区 B | 普通 |
| MySQL Master | 数据库 · 主（写） | 私有子网，居中 | 紫色描边 + glow |
| MySQL Slave | 数据库 · 从（读） | 私有子网，居左 | 紫色描边 |
| Redis 集群 | 缓存 · Cluster | 私有子网，居右 | 紫色描边 |

## 链路（方向 + 协议/端口）

| 链路 | 方向 | 标签 | 线型/颜色 |
|---|---|---|---|
| 用户 → CDN | 单向 | HTTPS:443 | 实线·青 |
| CDN → ALB | 单向（回源） | HTTPS:443 · 回源 | 实线·青 |
| ALB → 应用 A | 单向 | HTTP:8080 | 实线·青 |
| ALB → 应用 B | 单向 | HTTP:8080 | 实线·青 |
| 应用 A → MySQL 主 | 单向（写） | 写 · TCP:3306 | 实线·青 |
| 应用 B → MySQL 主 | 单向（写） | 写 · TCP:3306 | 实线·青 |
| 应用 A → MySQL 从 | 单向（读） | 读 · TCP:3306 | 实线·紫 |
| 应用 B → MySQL 从 | 单向（读） | 读 · TCP:3306 | 实线·紫 |
| 应用 A → Redis | 单向 | 缓存 · TCP:6379 | 实线·紫 |
| 应用 B → Redis | 单向 | 缓存 · TCP:6379 | 实线·紫 |
| MySQL 主 → MySQL 从 | 单向 | 主从复制 · binlog | 虚线·灰（异步） |

## 图例

- 青色实线 = 请求主链路 / 写路径
- 紫色实线 = 读 / 缓存
- 灰色虚线 = 异步复制
