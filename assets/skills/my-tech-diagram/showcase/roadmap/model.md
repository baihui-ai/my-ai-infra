# 2026-h2-roadmap 关系模型

## 图类型
Roadmap（里程碑图 / 路线图）—— **Timeline 式**变体。

变体选型理由：条目总数 6（4 主题 + 2 里程碑）< 15，且未提供团队/产品线归属信息，
属「单一产品线、事件少」场景，按 reference 选用 Timeline 式（单条时间轴 + 里程碑菱形），
不采用 Swimlane 式（避免编造泳道归属）。

## 时间刻度
- 粒度：季度（Q3 2026 / Q4 2026），辅以月份刻度（7月–12月）
- 方向：左 → 右流逝

## 分组 / 归属
- 单一产品线整体呈现，无泳道划分（用户未提供团队归属；已在交付说明中注明）

## 状态
- 用户未提供各条目状态（planned / in-progress / done），全部按「planned」统一呈现，不做状态色区分

## 风格
- Claude 风（用户指定）：暖米白底 #F5F1EA、赭橙主色 #D97757、衬线标题、节点卡 #FDFBF7、圆角 rx=10、强调用 3px 主色顶条
