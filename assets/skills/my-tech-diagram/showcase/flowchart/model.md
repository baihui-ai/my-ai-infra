# 售后退款流程图 — 关系模型

- 图类型:Flowchart(流程图)
- 风格:简洁风 minimal(用户已指定,跳过风格询问)
- 流向:自上而下主轴;分支/回流走右侧与底部外侧通道,不与主流交叉

## 节点

| ID | 名称 | 类型(形状) |
|---|---|---|
| A | 用户申请退款 | 开始(圆角矩形 Terminator) |
| B | 校验订单状态 | 处理(矩形) |
| D1 | 已发货? | 判断(菱形) |
| C | 用户寄回商品 | 处理(矩形) |
| V | 仓库验收 | 处理(矩形) |
| D2 | 完好? | 判断(菱形) |
| E | 执行退款 | 处理(矩形) |
| F | 拒绝退款 | 处理(矩形) |
| G | 退款到账 | 处理(矩形) |
| H | 结束 | 结束(圆角矩形 Terminator) |

## 布局规划(连线不相交)

- 主轴(x=340):A → B → D1 → E → G → H,纯垂直连线。
- 右侧子流程列(x=780):C → V → D2,纯垂直连线。
- D1 的「是」从菱形右顶点水平进入 C 左侧,不经过任何节点。
- D2 的「是」走外侧通道:左顶点 → x=560 垂直通道 → 水平进入 E 右缘;通道 x=560 位于两列之间,不与任何节点/连线相交。
- F(拒绝退款)在 D2 右侧同级(x=1120),「否」水平直连。
- F → H 走底部外侧通道(y=748):F 底部 → 下行 → 左行 → x=600 通道上行 → 进入 H 右缘;全程在主流之下/之外,无交叉。
